# Desktop-D30

Tired of building labels on your phone and want to have a **real** label maker? Desktop-D30 is here to help you.

## Building

### Build

```
make build
```

### Build and run:

```
make run
```

### Clean Build Cache

```
make clean
```

### Clear the build cache and Re-make

```
make re
```

## Features

- [x] Create labels
  - [x] Generate QR Codes
  - [x] Generate Barcodes
  - [x] Put custom images on the label
  - [x] Put custom text on the label
  - [x] Add basic shapes to the label
  - [x] Put a basic border on the label
  - [x] Import a .csv to batch create labels.
- [x] Prints Directly to the Phenomemo D30 printer
- [x] Folder based Icon Store.
