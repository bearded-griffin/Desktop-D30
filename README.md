# LabelForge

Tired of building labels on your phone and want to have a **real** label maker? Label Forge is here to help you. No pay walls, No barriers, just labels...

## Building 

### Build
```
make build
```

### Build and run:
```
make run
```

### Clean Build Cache
```
make clean
```

### Clear the build cache and Re-make
```
make re
```

## Features

- [x] Create labels
  - [x] Generate QR Codes
  - [x] Put custom images on the label
  - [x] Put custom text on the label
  - [x] Import a .csv to batch create labels.
- [x] Prints Directly to the Phenomemo D30 printer
- [ ] Folder based Icon Store.
