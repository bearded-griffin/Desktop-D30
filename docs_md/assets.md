# Managing Assets

Desktop-D30 allows you to customize your labels with your own fonts, icons, and decorative borders.

## Custom Fonts

You can use any `.ttf` or `.otf` font file in your designs.

1. Select a **Text** or **Data Field** object on your canvas.
2. In the Side Inspector, under the **Properties** section, click **Import Font...**.
3. Select your font file.
4. Your font is now permanently available in the **Font** dropdown menu under the "User Fonts" section.

!!! info "System Fonts"
    Desktop-D30 also automatically detects fonts already installed on your Windows or Linux system.

## Icon Library

The Icon Library is where you store and organize small graphics used in your labels.

### Importing Icons
1. Go to **Assets -> Manage Icon Library**.
2. Click **Import Icons...** and select one or more image files (`.png`, `.jpg`, `.bmp`).
3. These icons will now appear in the **Add Icon** popup on the sidebar.

### Organizing Icons
In the Icon Manager, you can:
* **Tag Icons**: Add descriptive tags to icons to make them searchable.
* **Rename**: Give icons custom display names.
* **Categories**: Move icons into different folders/categories using the "Move to Category" dropdown.

## Deco Borders

Decorative borders are special graphics that frame your label.

### Importing Borders
1. Go to **Assets -> Manage Deco Borders**.
2. Click **Import Borders...** and select your border images.
3. These will now be available when using the **Deco Border** tool in the sidebar.

!!! tip "Scaling Borders"
    When you add a Deco Border, the application automatically scales it to fit your current label size. You can adjust its thickness and corner radius in the Properties panel.
