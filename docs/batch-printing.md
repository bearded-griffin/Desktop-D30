# Batch Printing with CSV

Batch printing allows you to create many labels at once using data from a spreadsheet.

## Preparing your CSV
1. Create a spreadsheet with headers (e.g., `Product`, `Price`, `SKU`).
2. Fill in your data rows.
3. Save the file as a `.csv` (Comma Separated Values).

## Setting up Data Fields
1. In Desktop-D30, go to **File -> Load CSV Data...** and select your file.
2. Click **Add Object -> Data Field**.
3. In the Inspector, select the column name from your CSV that you want to link to this field.
4. You can navigate through your data using the navigator at the bottom of the screen to preview how each label will look.

## Printing
Once you are happy with the layout, go to **File -> Batch Print**. Select the range of rows you wish to print and click **Start Print**.
