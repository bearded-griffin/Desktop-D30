# Understanding the Interface

The Desktop-D30 interface is designed to keep your focus on the label design.

## Main Canvas
The center of the screen is your label canvas. 
* **Navigation**: Use the mouse wheel to zoom and Right-Click + Drag to pan the view.
* **Selection**: Click an object to select it. Hold `Shift` to select multiple objects.
* **Modification**: Drag the handles on the corners of a selected object to resize it.

## Side Inspector
The panel on the left allows you to:
* **Add Objects**: Insert text, barcodes, QR codes, or shapes.
* **Manage Assets**: Browse the built-in icon library or add your own images.
* **Properties**: Change fonts, colors, and line thickness for selected objects.

## Menu Bar
* **File**: Save and Load your projects.
* **Assets**: Manage your local icon and border libraries.
* **Printer**: Connect to your D30 device via Bluetooth.
* **Help**: Access this user guide and application information.
