# Understanding the Interface

The Desktop-D30 interface is designed to keep your focus on the label design.

## Main Canvas
The center of the screen is your label canvas. 
* **Navigation**: Use the mouse wheel to zoom and Right-Click + Drag to pan the view.
* **Selection**: Click an object to select it. Hold `Shift` to select multiple objects.
* **Modification**: Drag the handles on the corners of a selected object to resize it.

## Side Inspector
The panel on the left is your primary control center. It is divided into several sections:

### Project Settings
* **Canvas Size**: Choose the physical dimensions of your label (e.g., 12mm x 40mm).
* **Show Grid**: Toggle the visual alignment grid.
* **Dark Mode**: Switch between light and dark user interface themes.

### Data Source
This section only appears after you have loaded a CSV file via **File -> Load CSV Data**.
* Use the **<<** and **>>** buttons to flip through your data rows.
* The canvas will update in real-time to show how your label looks with actual data.

### Object Tree
A list of all objects currently on your canvas.
* **Selection**: Click an item in the tree to select it on the canvas.
* **Z-Order**: Objects at the bottom of the list are drawn on top of objects at the top of the list.

### Properties Panel
This section updates dynamically based on what you have selected.
* **Common**: Adjust the precise **X** and **Y** coordinates.
* **Text/Field**: Change font size, font family, and the text content.
* **Shapes**: Adjust line thickness and dimensions.
* **Images/Icons**: Change width, height, or swap the image file.
* **Barcode/QR**: Adjust the size and the encoded data.

### Tools
A grid of buttons to quickly add new elements:
* **Basics**: Text and Data Fields.
* **Media**: QR Codes and Barcodes.
* **Graphics**: Custom Images and searchable Icons.
* **Shapes**: Lines, Rectangles, and Circles.
* **Decor**: Full-label Deco Borders.

## Menu Bar
* **File**: Save and Load your projects, or load CSV data.
* **Edit**: Access Undo, Redo, Cut, Copy, and Paste commands.
* **Assets**: Manage your local icon and border libraries.
* **Printer**: Connect to your D30 device via Bluetooth.
* **Help**: Access this user guide and application information.
