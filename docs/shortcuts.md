# Keyboard & Mouse Shortcuts

Efficiency is key when designing labels. Desktop-D30 supports standard shortcuts for common operations.

## General Shortcuts

| Shortcut | Action |
| :--- | :--- |
| `Ctrl + S` | Save current project |
| `Ctrl + L` | Load project |
| `Alt + F4` | Exit application |

## Editing Shortcuts

| Shortcut | Action |
| :--- | :--- |
| `Ctrl + Z` | Undo last action (up to 50 steps) |
| `Ctrl + Y` | Redo last undone action |
| `Ctrl + Shift + Z` | Alternative Redo shortcut |
| `Ctrl + C` | Copy selected objects |
| `Ctrl + X` | Cut selected objects |
| `Ctrl + V` | Paste objects from clipboard |
| `Delete` / `Backspace` | Remove selected objects |

## Precision Nudging

When one or more objects are selected, you can use the arrow keys for fine-grained movement:

* **Arrow Keys**: Move selection by 1 unit.
* **Shift + Arrow Keys**: Move selection by 10 units.

## Canvas Navigation

* **Mouse Wheel**: Zoom in and out.
* **Space + Left Click & Drag**: Pan the canvas.
* **Right Click & Drag**: Pan the canvas.
* **Shift + Left Click**: Select multiple objects or toggle selection.
