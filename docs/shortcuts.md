# Keyboard & Mouse Shortcuts

Efficiency is key when designing labels. Desktop-D30 supports a wide array of shortcuts for power users who prefer the keyboard.

## General Shortcuts

| Shortcut | Action |
| :--- | :--- |
| `Ctrl + S` | Save current project |
| `Ctrl + L` | Load project |
| `Alt + F4` | Exit application |

## Adding Objects

| Shortcut | Action |
| :--- | :--- |
| `Alt + T` | Add Text Object |
| `Alt + F` | Add Data Field |
| `Alt + Q` | Add QR Code |
| `Alt + B` | Add Barcode |
| `Alt + L` | Add Line |
| `Alt + R` | Add Rectangle |
| `Alt + C` | Add Circle |
| `Alt + D` | Add Border |

## Editing & Rotation

| Shortcut | Action |
| :--- | :--- |
| `Ctrl + Z` | Undo last action (up to 50 steps) |
| `Ctrl + Y` | Redo last undone action |
| `Ctrl + Shift + Z` | Alternative Redo shortcut |
| `Ctrl + C` | Copy selected objects |
| `Ctrl + X` | Cut selected objects |
| `Ctrl + V` | Paste objects from clipboard |
| `Delete` / `Backspace` | Remove selected objects |
| `Ctrl + [` | Rotate selection Counter-Clockwise (15°) |
| `Ctrl + ]` | Rotate selection Clockwise (15°) |
| `Ctrl + Shift + [` | Rotate selection CCW (90°) |
| `Ctrl + Shift + ]` | Rotate selection CW (90°) |

## Precision Nudging

When one or more objects are selected, you can use the arrow keys for fine-grained movement:

* **Arrow Keys**: Move selection by 1 unit.
* **Shift + Arrow Keys**: Move selection by 10 units.

## Printing

| Shortcut | Action |
| :--- | :--- |
| `Ctrl + P` | Print Single Label |
| `Ctrl + Shift + B` | Open Batch Print dialog |
| `Ctrl + Shift + P` | Open Sequence Print dialog |

## Canvas & View

| Shortcut | Action |
| :--- | :--- |
| `Ctrl + G` | Toggle Background Grid |
| `Ctrl + H` | Toggle Snapping (Grid & Objects) |
| `Mouse Wheel` | Zoom in and out |
| `Space + Left Drag` | Pan the canvas |
| `Right Click & Drag` | Pan the canvas |
| `Shift + Left Click` | Multi-select toggle |
